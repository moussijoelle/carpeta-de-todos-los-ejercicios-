1. En quoi consiste l'exercice ?

Imagine que tu gères une petite librairie sur ton ordinateur. Tu as une liste de livres et tu veux pouvoir les ajouter, les modifier, les supprimer et les consulter.

C'est ce qu'on appelle un CRUD :

LettreMot espagnolSignification
CCrearCréer — ajouter un livre
RLeerLire — afficher un livre
UActualizarMettre à jour — modifier stock et prix
DBorrarSupprimer — effacer un livre

Chaque livre a :

  • ISBN — identifiant unique (comme un DNI)
  • Título — titre
  • Autor — auteur
  • Stock — nombre d'exemplaires
  • Precio — prix en euros

Au départ, 2 livres sont déjà en mémoire. L'utilisateur choisit une opération en haut, tape un ISBN, et le programme réagit.

2. Qu'est-ce que l'ISBN ? (explication simple)

ISBN = International Standard Book Number → le DNI du livre.

Dans la vie réelleDans l'exercice
Chaque personne a un DNI uniqueChaque livre a un ISBN unique
Sert à identifier quelqu'unSert à trouver un livre dans la liste

Exemple : 978-0307474728 → Cien años de soledad de Gabriel García Márquez.

À quoi sert-il ici ?

  1. Tu écris l'ISBN dans le formulaire.
  2. Le programme cherche si un livre avec cet ISBN existe déjà.
  3. Selon le mode (ajouter, modifier, supprimer, afficher), il fait une chose différente.

C'est pour ça que l'ISBN est en dehors du fieldset : c'est la clé de recherche, traitée à part.

3. Qu'est-ce qu'un fieldset ? (explication simple)

Un fieldset est une boîte qui regroupe plusieurs champs d'un formulaire.

┌─ Données du livre ─────────────┐
│  Título:  [________]            │
│  Autor:   [________]            │
│  Stock:   [____]  Precio: [____]│
└─────────────────────────────────┘

Dans l'exercice, le fieldset id="campos-libro" regroupe : titre, auteur, stock et prix.

Pourquoi disabled ?

  • disabled = bloqué, on ne peut pas écrire.
  • Au début, tout le groupe est fermé.
  • Quand tu choisis une opération et tapes l'ISBN, le JavaScript ouvre les champs nécessaires.
  • C'est plus simple de bloquer/débloquer tout le groupe que chaque champ un par un.

Attribut data-info :

ValeurChampsEn mode MODIFICAR (2)
fijotítulo, autorBloqués — on ne change pas le titre ni l'auteur
modificablestock, precioOuverts — seuls le stock et le prix changent

Sa méthode de pensée :

  1. D'abord définir ce qu'est un livre (classe)
  2. Ensuite créer où on stocke les livres (tableau)
  3. Puis construire l'interface (HTML)
  4. Enfin écrire la logique qui connecte tout (main.js)

5. Explication du HTML (index.html)

En-tête (head)

  • <!DOCTYPE html> — dit au navigateur que c'est une page web moderne.
  • charset UTF-8 — affiche correctement les accents (á, ñ, é…).
  • viewport — la page s'adapte aux téléphones.
  • Tailwind CSS — bibliothèque de styles. Les classes comme bg-blue-600 viennent de là.

Barre de navigation (4 boutons)

BoutonidoperacionActual
1. AGREGARbtn-agregar1
2. MODIFICARbtn-modificar2
3. ELIMINARbtn-eliminar3
4. MOSTRARbtn-mostrar4

Le HTML prépare les boutons. Le JavaScript décide ce qu'ils font via la variable operacionActual.

Indicateur de mode

id="estado-operacion" — message qui change selon le mode : « MODO: 1. AGREGAR LIBRO », etc. L'utilisateur sait toujours où il en est.

Formulaire

  • id="isbn" — champ clé, disabled au départ. Activé quand on choisit une opération.
  • id="campos-libro" — fieldset avec titre, auteur, stock, prix.
  • id="acciones-formulario" — boutons Guardar / Cancelar, cachés (hidden) au début.
  • id="dialog-informativo" — fenêtre popup pour les messages (succès, erreur…).

Ordre des scripts (important)

<script src="./js/clase-libro.js"></script>  <!-- 1. le modèle -->
<script src="./js/libros.js"></script>         <!-- 2. les données -->
<script src="./js/main.js"></script>           <!-- 3. la logique -->

Note : le fichier classe s'appelle clase.libro.js à la racine du projet. Vérifie que le chemin dans index.html pointe vers le bon fichier.

6. Explication de clase.libro.js

Une classe = un moule. Chaque livre est fabriqué avec ce moule.

Champs privés (#)

class Libro {
  #isbn;
  #titulo;
  #autor;
  #stock;
  #precio;
}

Le # = privé. On ne peut pas modifier directement de l'extérieur. Seuls les getters et méthodes y accèdent. C'est l'encapsulation.

Constructeur

constructor(isbn, titulo, autor, stock, precio) {
  this.#isbn = isbn.trim();
  ...
}

new Libro("978-...", "Cien años...", "García Márquez", 15, 19.99) remplit les 5 propriétés. trim() enlève les espaces autour de l'ISBN.

Getters

getIsbn()  { return this.#isbn; }
getTitulo() { return this.#titulo; }
...

Pour lire les valeurs sans les exposer directement.

Méthode de modification

actualizarStockYPrecio(nuevoStock, nuevoPrecio) {
  this.#stock = parseInt(nuevoStock);
  this.#precio = parseFloat(nuevoPrecio);
}
  • parseInt → nombre entier (15 unités)
  • parseFloat → nombre décimal (19.99 €)

Seule façon autorisée de modifier stock et prix en mode MODIFICAR.

toString()

Transforme le livre en texte : ISBN: 978-... | Título: Cien años... | Precio: €19.99

7. Explication de libros.js

const baseDatosLibros = [
  new Libro("978-0307474728", "Cien años de soledad", "Gabriel García Márquez", 15, 19.99),
  new Libro("978-0399589430", "Breves respuestas...", "Stephen Hawking", 8, 14.50)
]
  • baseDatosLibros = un tableau qui simule une base de données.
  • Chaque élément est un objet Libro.
  • console.table() affiche joliment la liste dans la console (F12).
  • Tout est en mémoire : si tu recharges la page, tu retrouves les 2 livres de départ.

Mappage du DOM

const btnAgregar = document.getElementById('btn-agregar');

...

Le DOM = la page HTML en objets JavaScript. Ta prof crée des raccourcis pour ne pas répéter document.getElementById partout.

Fonctions utilitaires

mostrarAviso(titulo, mensaje) — affiche la fenêtre popup.

gestionarPermisosCampos(operacion) — cœur des permissions :

  • Opération 3 ou 4 → tout le fieldset bloqué
  • Opération 1 → tous les champs ouverts
  • Opération 2 → seuls stock et prix modifiables

resetearFormulario() — remet tout à zéro.

Recherche par ISBN

const buscarLibroPorIsbn = (isbnValue) => {
  let i = 0;
  while (i < baseDatosLibros.length && !encontrado) {
    if (isbnValue === baseDatosLibros[i].getIsbn()) {
      indice = i;
      encontrado = true;
    }
    i++;
  }
  posicionLibro = indice;
}

Parcourt le tableau avec une boucle while jusqu'à trouver l'ISBN ou atteindre la fin.

Les 4 opérations CRUD

FonctionAction
mostrarLibroEnFormularioRemplit les champs avec les données du livre trouvé
guardarLibroEnFormularionew Libro(...) + .push() dans le tableau
modificarLibroEnFormularioAppelle actualizarStockYPrecio()
eliminarLibroEnFormulario.splice(posicionLibro, 1) — supprime 1 élément

Pattern des 4 boutons du menu

Chaque bouton (agregar, modificar, eliminar, mostrar) fait la même chose :

  1. operacionActual = X
  2. resetearFormulario()
  3. inputIsbn.disabled = false
  4. inputIsbn.focus() — curseur dans le champ ISBN
  5. Change le texte de estado-operacion

Soumission du formulaire

const procesarEnvio = (e) => {
  e.preventDefault();
  switch (operacionActual) {
    case 1: guardarLibroEnFormulario(); break;
    case 2: modificarLibroEnFormulario(); break;
    case 3: eliminarLibroEnFormulario(); break;
    case 4: mostrarLibroEnFormulario(); break;
  }
  resetearFormulario();
}

e.preventDefault() empêche le navigateur de recharger la page. Le switch dirige vers la bonne fonction.

Touche Entrée sur l'ISBN

Quand tu appuies sur Entrée dans le champ ISBN :

  1. Cherche le livre
  2. Si trouvé → affiche ses données
  3. Ajuste les permissions selon l'opération
  4. Montre les boutons Guardar / Cancelar
