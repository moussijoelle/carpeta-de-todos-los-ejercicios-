Galerie de photos avec API

Guide explicatif — pour comprendre l'exercice sans connaissances en programmation

En une phrase, c'est quoi ?

Tu dois créer une page web qui affiche des photos prises depuis Internet, via une API — une sorte de « porte » qui te donne accès à des images sans les télécharger toi-même.

C'est comme une vitrine de photos : tu tapes un mot (plage, voyage, chat…), et la page te montre des images sur ce thème.

Les mots importants (version simple)

Mot Explication simple
Galerie de photos Une page avec plusieurs images disposées en grille, comme sur Instagram ou Pinterest.
API Un service en ligne qui envoie des données à ton site. Ici : des photos.
Responsiva La page s'adapte au téléphone, à la tablette et à l'ordinateur.
HTML La structure de la page : titres, boutons, zones pour les images.
CSS / Tailwind Le style : couleurs, tailles, mise en page.
JavaScript La logique : quand tu cliques sur « Buscar », le site va chercher les photos.

Ce que demande l'exercice, concrètement

  1. Choisir une API gratuite de photos
    → Tu as choisi Unsplash (photos de qualité, gratuites pour apprendre).
  2. Faire une galerie 100 % responsiva
    → Sur mobile : 1 colonne. Sur grand écran : plusieurs colonnes. Tout doit rester lisible et joli.
  3. Utiliser l'API
    → Ton site ne stocke pas les photos. Il demande à Unsplash : « Donne-moi des photos de plage », et Unsplash répond avec une liste d'images.

Comment ça marche, comme une histoire

Imagine ta page comme un restaurant :

  1. Le client (toi) écrit « voyage » dans la barre de recherche et clique sur Buscar.
  2. Le serveur (ton JavaScript) porte la commande à la cuisine (l'API Unsplash).
  3. La cuisine renvoie un plateau de photos sur le thème « voyage ».
  4. Le serveur les dispose joliment sur la table (la galerie à l'écran).

Si tu cliques sur Cargar más, le serveur redemande : « Encore des photos, page suivante, s'il vous plaît. »

Ce que tu as dans ton projet

Tu as deux fichiers principaux :

index.html — la « coquille » de la page

  • Le titre « Galería de Fotos »
  • La barre de recherche
  • L'endroit où les photos apparaissent
  • Le bouton jour / nuit
  • Le bouton « Cargar más »

js/app.js — le « cerveau »

C'est lui qui :

  • parle à Unsplash ;
  • reçoit les photos ;
  • les affiche ;
  • gère la recherche, le chargement et le thème clair/sombre.

Ton code est bien organisé :

  1. d'abord le DOM (les éléments de la page) ;
  2. puis les variables ;
  3. puis les fonctions ;
  4. à la fin, l'exécution (iniciarAplicacion()).

Pourquoi une « clé d'accès » (Access Key) ?

Unsplash veut savoir qui utilise son service. Ta Access Key, c'est comme une carte d'identité de ton projet — pas ton mot de passe.

Sans elle, la porte (l'API) ne s'ouvre pas.

Ce que « responsiva » veut dire pour toi

  • Téléphone : les photos sont les unes sous les autres.
  • Tablette : 2 ou 3 colonnes.
  • Ordinateur : jusqu'à 4 colonnes.

Tu n'as pas besoin de zoomer ou faire défiler horizontalement : tout s'adapte tout seul grâce à Tailwind.

En résumé pour ton prof ou pour toi

J'ai créé une galerie web responsive qui utilise l'API Unsplash. L'utilisateur peut chercher un thème, voir les photos en grille, charger plus de résultats, et changer entre mode jour et mode nuit. Le JavaScript est structuré avec des fonctions nommées et une séparation entre la logique et l'affichage.

Résumé des étapes réalisées

Objectif

Créer une galerie web 100 % responsive qui récupère des photos via une API publique et gratuite.

Technologies choisies

Partie Technologie
Structure HTML
Styles Tailwind CSS (CDN)
Logique JavaScript
API Unsplash

Fichiers du projet

  • index.html — page principale
  • js/app.js — logique et connexion à l'API
  • guia.html — ce guide explicatif

Étapes suivies

  1. Configurer Unsplash — inscription, confirmation de l'e-mail, création de l'application « Galería fotos » et obtention de l'Access Key.
  2. Créer index.html — en-tête, barre de recherche, grille de photos, bouton « Cargar más », mode jour/nuit et design responsive avec Tailwind.
  3. Créer js/app.js — connexion à l'API Unsplash pour chercher des photos par thème et les afficher dans la galerie.
  4. Corriger le bouton « Buscar » — ajout de l'Access Key et suppression de required sur le champ de recherche.
  5. Ajouter le thème jour / nuit — bouton qui change l'apparence et sauvegarde la préférence dans localStorage.
  6. Structurer le code — ordre : mapeo del DOM → variables → fonctions → exécution. Fonctions nommées, indépendantes, et une seule (actualizarInterfaz) qui modifie le DOM.
  7. Documenter — commentaires dans app.js et ce guide en français.

Fonctionnalités finales

  • Recherche par thème (voyage, plage, architecture…)
  • Galerie responsive (1 à 4 colonnes selon l'écran)
  • « Cargar más » pour voir plus de photos
  • Mode jour et mode nuit
  • Nom de l'auteur sur chaque photo (exigence d'Unsplash)

Phrase pour rendre l'exercice

J'ai créé une galerie web responsive avec HTML, Tailwind et JavaScript qui consomme l'API Unsplash. L'utilisateur peut chercher des photos par thème, charger plus de résultats et basculer entre le mode clair et le mode sombre. Le code est organisé avec des fonctions nommées et une séparation entre la logique et la présentation.
