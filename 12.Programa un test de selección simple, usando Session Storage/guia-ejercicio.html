¿En qué consiste el ejercicio?

Debes crear una página web con un cuestionario (un test tipo examen) sobre HTML. El usuario verá preguntas con 4 opciones, podrá navegar entre ellas, verificar sus respuestas y al final ver los resultados guardados.

Cuestionario sobre HTML

Pregunta 1 de 20

¿Cuál es el código HTML correcto para un salto de línea?

PREGUNTA ANTERIOR VERIFICAR PREGUNTA SIGUIENTE REINICIAR TEST
En resumen: es un QCM interactivo donde cada pregunta es un objeto, los cambios se guardan en sessionStorage y al terminar se muestran los resultados.

La clase Pregunta

Una clase es como un molde: defines una vez cómo es una pregunta y luego creas tantas preguntas como necesites.

Todas las preguntas se guardan en un array llamado preguntas.

Atributo Qué significa
texto El enunciado de la pregunta
opciones Las 4 respuestas posibles (a, b, c, d)
opcionCorrecta La letra o índice de la respuesta correcta
opcionSeleccionada Lo que el usuario ha elegido (vacío al inicio)
puntosPregunta Puntos que vale la pregunta (ej: 5)
puntosAsignados Puntos que el usuario ha conseguido (0 si falla)
justificacion Texto que explica por qué la respuesta es correcta 
class Pregunta {
  constructor(texto, opciones, opcionCorrecta, puntosPregunta, justificacion) {
    this.texto = texto;
    this.opciones = opciones;
    this.opcionCorrecta = opcionCorrecta;
    this.opcionSeleccionada = null;
    this.puntosPregunta = puntosPregunta;
    this.puntosAsignados = 0;
    this.justificacion = justificacion;
  }
}

Los botones y qué debe hacer cada uno

VERIFICAR El más importante

  1. Comprueba si opcionSeleccionada coincide con opcionCorrecta.
  2. Si es correcta → asigna los puntos a puntosAsignados.
  3. Muestra una ventana modal con el texto de justificacion.

PREGUNTA SIGUIENTE / ANTERIOR

Cambian la pregunta visible. Actualizan el contador «Pregunta X de 20».

REINICIAR TEST

Borra el progreso y vuelve a empezar desde la pregunta 1.

Session Storage — la parte clave del ejercicio

Regla del ejercicio: cada vez que cambie cualquier dato de un objeto del array preguntas (por ejemplo, cuando el usuario elige una respuesta), debes guardar todo el array en sessionStorage. 
// Guardar
sessionStorage.setItem("preguntas", JSON.stringify(preguntas));

// Leer al cargar la página
const guardadas = sessionStorage.getItem("preguntas");
if (guardadas) {
  preguntas = JSON.parse(guardadas);
}

¿Cuándo guardar?

  • Cuando el usuario selecciona una opción.
  • Cuando pulsa VERIFICAR (cambian los puntos).
  • Cualquier cambio en los objetos del array.

¿Por qué JSON?

Session Storage solo guarda texto. Por eso usas JSON.stringify al guardar y JSON.parse al leer. (Más detalle en guia.html.)

Al finalizar el test

Cuando el usuario termine las 20 preguntas, el programa debe:

  1. Leer el array preguntas desde sessionStorage.
  2. Mostrar su contenido en pantalla (puntos, respuestas, etc.).

Flujo completo del programa

Usuario abre index.html ↓ ¿Hay preguntas en sessionStorage? ↓ Sí ↓ No Recuperar estado Crear 20 preguntas nuevas ↓ Mostrar pregunta actual ↓ Usuario elige una opción ↓ Actualizar opcionSeleccionada → guardar en sessionStorage ↓ Usuario pulsa VERIFICAR ↓ ¿Correcta? → puntosAsignados = puntosPregunta Mostrar modal con justificacion → guardar en sessionStorage ↓ Siguiente pregunta... hasta la 20 ↓ Fin → leer sessionStorage y mostrar resultados

Orden recomendado para programar

  1. Crear el HTML con la estructura visual (título, pregunta, opciones, botones).
  2. Crear la clase Pregunta y el array con las 20 preguntas.
  3. Mostrar una pregunta en pantalla y navegar entre ellas.
  4. Detectar la opción seleccionada y guardarla.
  5. Implementar el botón VERIFICAR y el modal.
  6. Añadir sessionStorage (guardar y recuperar).
  7. Mostrar resultados finales al terminar.
