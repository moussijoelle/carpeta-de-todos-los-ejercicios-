Explication de l'exercice (en français)

Bonjour !

Tu as déjà une page qui montre des Pokémon. C'est bien. Cet exercice, c'est l'étape suivante : tu vas apprendre à garder tes Pokémon préférés, même si tu fermes le navigateur.

Ce que tu as déjà (le point de départ)

Imagine une application en deux colonnes :

  • À gauche : une liste de noms (Bulbasaur, Charmander…). Tu peux tourner les pages avec les flèches.
  • À droite : quand tu cliques sur un nom, tu vois sa fiche — photo, numéro, types.

Tout ça vient d'Internet, d'un site gratuit qui s'appelle PokéAPI. Ta page demande les infos et les affiche. C'est déjà très bien.

Mais : si tu fermes l'onglet, tout disparaît. La page ne se souvient de rien.

Ce que l'exercice te demande d'ajouter

1. Un bouton « Ajouter aux favoris »

Quand tu vois la fiche d'un Pokémon à droite (avec sa grande image), tu dois ajouter un bouton.

Ce bouton, c'est comme dire : « Celui-là, je l'aime. Je veux le garder. »

Tu cliques → le programme enregistre ce Pokémon quelque part.

2. Où on enregistre ? Dans le localStorage

Le localStorage, c'est une petite mémoire dans ton navigateur (Chrome, Firefox…).

  • Ce n'est pas sur Internet.
  • Ce n'est pas sur la PokéAPI.
  • C'est chez toi, dans ton ordinateur, dans le navigateur.

Analogie simple :
La PokéAPI, c'est une bibliothèque géante où tu vas lire des livres.
Le localStorage, c'est ton carnet personnel où tu notes : « J'adore Pikachu, j'adore Eevee… »

Même si tu fermes la page et tu reviens demain, ton carnet est toujours là.

3. Une fonction pour sauvegarder

Tu dois écrire une fonction (une petite recette de code) qui :

  1. Prend les infos du Pokémon (nom, image, numéro…).
  2. Les met dans le localStorage.
  3. Peut-être évite de sauver deux fois le même Pokémon.

En langage humain : « Quand je clique sur le bouton, appelle la fonction qui écrit dans mon carnet. »

4. Un programme pour « auditer » le localStorage

Auditer, ça veut dire : regarder ce qui est stocké, comme ouvrir ton carnet et lire toutes les pages.

Le localStorage fonctionne avec des clés (des noms) et des valeurs (le contenu). Par exemple :

  • Clé : pokemonesFavoritos
  • Valeur : la liste de tes favoris en texte

L'exercice te demande de faire une boucle — répéter une action plusieurs fois — pour parcourir tout ce qui est sauvegardé :

Pour chaque chose dans le localStorage :
  → lire le nom (la clé)
  → lire le contenu (la valeur)
  → l'afficher (souvent dans la console)

C'est comme feuilleter ton carnet page par page et dire à voix haute ce qu'il y a écrit.

Le parcours complet, étape par étape

1. Tu ouvres la page ↓ 2. La liste de Pokémon s'affiche (comme avant) ↓ 3. Tu cliques sur un nom → sa fiche apparaît à droite ↓ 4. Tu vois le NOUVEAU bouton « Ajouter aux favoris » ↓ 5. Tu cliques → le Pokémon est sauvé dans le localStorage ↓ 6. Tu fermes le navigateur, tu reviens → tes favoris sont toujours là ↓ 7. Tu lances l'audit → tu vois tout ce qui est enregistré

Ce que tu n'as pas à refaire

Tu ne recommences pas tout depuis zéro. Tu modifies le programme de la prof :

  • La liste à gauche → tu gardes
  • Le clic pour voir le détail → tu gardes
  • Les flèches suivant / précédent → tu gardes

Tu ajoutes seulement : le bouton favoris, la fonction de sauvegarde, la fonction d'audit.

En une phrase :

Tu transformes une page qui consulte des Pokémon sur Internet en une page qui te laisse aussi choisir tes préférés et les garder dans ton navigateur, comme des favoris sur ton téléphone.

Cambios en JavaScript (js/app.js)

1. Mapear los nuevos elementos HTML

const LISTA_FAVORITOS = document.getElementById('lista-favoritos');
const BTN_AUDITAR = document.getElementById('btn-auditar');

const CLAVE_FAVORITOS = 'pokemonesFavoritos';

2. Crear la función guardarEnFavoritos

Recibe un objeto con id, nombre, imagen, tipos y url. Usa getItem, JSON.parse, push, setItem y JSON.stringify:

const guardarEnFavoritos = (pokemon) => {
  try {
    const guardados = localStorage.getItem(CLAVE_FAVORITOS);
    let favoritos = guardados ? JSON.parse(guardados) : [];

    const yaExiste = favoritos.some((fav) => fav.id === pokemon.id);
    if (yaExiste) {
      alert(`${pokemon.nombre} ya está en favoritos`);
      return;
    }

    favoritos.push(pokemon);
    localStorage.setItem(CLAVE_FAVORITOS, JSON.stringify(favoritos));
    mostrarFavoritos();
    alert(`${pokemon.nombre} añadido a favoritos`);

  } catch (error) {
    console.error('No se pudo guardar en localStorage:', error);
  }
};

3. Modificar buscarDetallePokemon — añadir el botón

Dentro del template HTML del detalle, después de los tipos, añade el botón:

<button type="button" id="btn-favorito"
  class="mt-4 px-4 py-2 bg-amber-500 text-white rounded-lg hover:bg-amber-600">
  Añadir a Favoritos
</button>

Después de DETALLE_CONTENEDOR.innerHTML = ..., enlaza el clic:

document.getElementById('btn-favorito').addEventListener('click', () => {
  guardarEnFavoritos({ id, nombre, imagen, tipos, url });
});

4. Crear mostrarFavoritos (recomendado)

Lee localStorage al cargar y pinta las tarjetas en lista-favoritos:

const mostrarFavoritos = () => {
  if (!LISTA_FAVORITOS) return;

  const guardados = localStorage.getItem(CLAVE_FAVORITOS);
  if (!guardados) {
    LISTA_FAVORITOS.innerHTML = '<p class="text-slate-500">No hay favoritos aún</p>';
    return;
  }

  const favoritos = JSON.parse(guardados);
  let html = '';

  for (const fav of favoritos) {
    html += `
      <div class="text-center bg-white p-2 rounded shadow">
        <img src="${fav.imagen}" alt="${fav.nombre}" class="w-20 h-20 object-contain">
        <p class="text-sm font-bold">${fav.nombre}</p>
      </div>`;
  }

  LISTA_FAVORITOS.innerHTML = html;
};

Llama a mostrarFavoritos() al final del archivo, junto a cargarDatos().

5. Crear auditarLocalStorage (pide el ejercicio)

Bucle for tradicional con localStorage.key(i) y getItem():

const auditarLocalStorage = () => {
  console.log('=== Auditoría del localStorage ===');

  for (let i = 0; i < localStorage.length; i++) {
    const clave = localStorage.key(i);
    const valor = localStorage.getItem(clave);

    console.log(`Clave: ${clave}`);
    console.log(`Valor: ${valor}`);
  }
};

Enlazar al botón:

BTN_AUDITAR.addEventListener('click', auditarLocalStorage);

  6. Recarga la página → los favoritos siguen ahí
